# Test 2

Starter template for a SandOS federated module.

## Template tokens

The Dev Studio create-module flow is expected to replace these placeholders:

- `test-2`
- `Test 2`
- `test2Module`

## Commands

```bash
yarn install
yarn dev
yarn build
yarn preview
```

If dependency installation needs GitHub Packages access, provide `NODE_AUTH_TOKEN`
before running `yarn install`.
